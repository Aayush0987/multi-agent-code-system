# Multi-Agent Code Generation & Review System

A multi-agent system that plans, writes, tests, and reviews code for a given
task, using a supervisor orchestration pattern composed with a nested
debate/critique loop between a Coder and Reviewer agent, plus a
human-in-the-loop approval checkpoint.

See [`build-brief-multi-agent-code-system.md`](build-brief-multi-agent-code-system.md)
for the full project brief and [`PROGRESS.md`](PROGRESS.md) for current build
status. Full architecture writeup, example traces, and lessons learned land
here in the project's documentation phase.
